In **reinforcement learning (RL)** an agent learns what to do by trial and error: it acts, receives **rewards**, and gradually discovers which actions lead to the most reward over time. Nobody provides correct answers — only a score. RL is behind game-playing systems like AlphaGo, robot control, and the fine-tuning of language models from human feedback.

## The RL setting

At each step $t$ the agent observes state $s_t$, takes action $a_t$, and the environment returns reward $r_{t+1}$ and next state $s_{t+1}$. The goal is a **policy** maximising the expected discounted return $\sum_t \gamma^t r_{t+1}$. Formally the world is an [MDP](/ai/mdp) — but the agent does **not know** the transition probabilities or reward function; it must learn from experience.

| | Supervised learning | Reinforcement learning |
|---|---|---|
| Feedback | correct label for every input | a reward, often delayed |
| Data | fixed dataset | generated by the agent's own actions |
| Challenge | generalisation | exploration + credit assignment over time |

## Exploration vs exploitation

To get reward the agent should **exploit** the best action it knows — but to find better actions it must **explore** ones it hasn't tried enough. The simplest balance is **ε-greedy**: with probability ε take a random action, otherwise the greedy one. ε is often decayed over time. The lab's ε slider shows the trade-off: ε = 0 can lock into a poor route forever; a high ε keeps wandering into pits.

## Q-learning

Q-learning learns an **action-value function** $Q(s, a)$ — the expected return of taking action $a$ in state $s$ and acting optimally afterwards. After every step it applies a **temporal-difference (TD)** update:

$$
Q(s, a) \leftarrow Q(s, a) + \alpha\Big[\underbrace{r + \gamma \max_{a'} Q(s', a')}_{\text{TD target}} - Q(s, a)\Big]
$$

- $\alpha$ — learning rate; $\gamma$ — discount factor.
- The bracket is the **TD error**: how much better or worse things went than expected.
- It bootstraps: it learns from its own estimate of the next state.

Q-learning is **off-policy**: it learns the value of the *greedy* policy even while behaving ε-greedily, and it converges to the optimal $Q^*$ (with enough exploration and suitably decaying $\alpha$). The policy is then $\pi(s) = \arg\max_a Q(s, a)$ — the arrows in the lab.

```python
import random

# 1-D corridor: positions 0..5, start at 0, reward +1 for reaching 5, -0.01 per step
N, GOAL = 6, 5
ACTIONS = [-1, +1]                              # left, right
rng = random.Random(0)
Q = [[0.0, 0.0] for _ in range(N)]
alpha, gamma, epsilon = 0.5, 0.9, 0.2

for episode in range(200):
    s = 0
    while s != GOAL:
        if rng.random() < epsilon:
            a = rng.randrange(2)                                  # explore
        else:
            a = max(range(2), key=lambda i: (Q[s][i], rng.random()))  # exploit (random tie-break)
        s2 = min(N - 1, max(0, s + ACTIONS[a]))
        r = 1.0 if s2 == GOAL else -0.01
        target = r + (0 if s2 == GOAL else gamma * max(Q[s2]))
        Q[s][a] += alpha * (target - Q[s][a])                      # TD update
        s = s2

print("greedy policy:", ["L" if q[0] > q[1] else "R" for q in Q[:GOAL]])
print("V(s) = max Q :", [round(max(q), 3) for q in Q[:GOAL]])
```

```output
greedy policy: ['R', 'R', 'R', 'R', 'R']
V(s) = max Q : [0.622, 0.702, 0.791, 0.89, 1.0]
```

The values grow toward the goal by roughly a factor of $\gamma$ per step — the reward has propagated backwards through the TD updates.

## SARSA (on-policy)

SARSA updates toward the action actually taken next, $a'$, instead of the max:

$$
Q(s, a) \leftarrow Q(s, a) + \alpha\big[r + \gamma Q(s', a') - Q(s, a)\big]
$$

It learns the value of the policy it follows (including exploration), so it tends to learn **safer** paths near hazards (the classic "cliff walking" example), while Q-learning learns the optimal-but-risky edge path.

## Beyond tables

- **Deep Q-Networks (DQN)** — a neural network approximates $Q(s, a)$ from raw inputs (DeepMind played Atari games from pixels, 2015), stabilised with **experience replay** and a **target network**.
- **Policy gradient** methods (REINFORCE, **PPO**) optimise the policy directly — natural for continuous actions.
- **Actor–critic** — a policy (actor) plus a value function (critic).
- **Model-based RL** — learn a model of the environment and plan with it (AlphaZero combines search with learned networks).
- **RLHF** — reinforcement learning from human feedback, used to align chatbots ([LLMs](/ai/llms-generative-ai)).

## Key concepts

| Concept | Meaning |
|---|---|
| **Credit assignment** | which earlier actions deserve credit for a delayed reward |
| **Reward shaping** | adding intermediate rewards to speed learning (can cause unintended behaviour) |
| **Reward hacking** | the agent maximises the reward in ways the designer didn't intend |
| **Sample efficiency** | how much experience learning needs (RL is often data-hungry) |
| **On- vs off-policy** | learning about the policy being followed vs another (e.g. greedy) policy |

> [!WARNING]
> - ε = 0 from the start (no exploration → stuck on the first decent path).
> - Forgetting to stop bootstrapping at terminal states (their future value is 0).
> - Badly designed rewards that can be gamed.
> - Expecting tabular Q-learning to scale to huge state spaces — use function approximation.

## Interview questions

> [!INTERVIEW] What is the exploration–exploitation trade-off?
> Exploiting uses the best-known action to collect reward now; exploring tries other actions to discover better ones. Too little exploration gets stuck on a suboptimal policy; too much wastes reward. ε-greedy, decaying ε, UCB and optimistic initial values are common strategies.

> [!INTERVIEW] Explain the Q-learning update.
> $Q(s,a) \mathrel{+}= \alpha\,[r + \gamma\max_{a'}Q(s',a') - Q(s,a)]$: move the estimate toward the observed reward plus the discounted best estimated value of the next state.

> [!INTERVIEW] Q-learning vs SARSA?
> Q-learning is off-policy (targets the greedy action's value), SARSA is on-policy (targets the action actually taken). SARSA accounts for exploration risk and learns more conservative policies.
